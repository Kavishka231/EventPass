# Testing

From `backend/`, run `mvn spotless:check verify` with Java 21. Unit tests cover financial idempotency, JWT validation, refresh-token families, administrator lifecycle rules, HTTP security configuration, notification delivery transitions and ownership, the exact event envelope, and outbox retry behavior. Testcontainers applies every Flyway migration to PostgreSQL and verifies domain races, event cancellation, competing publishers, notification idempotency, concurrent last-admin protection, and the HTTP authorization matrix for roles, ownership, suspended accounts, invalid/expired JWTs, and refresh-token reuse. MockMvc contract tests additionally assert booking success payloads, validation failures, authentication failures, idempotency conflicts, bounded pagination, and the complete standardized error envelope through the real security and persistence stack. Authentication integration coverage exercises registration, duplicate registration, login, inactive-account enforcement, refresh rotation, logout, and replay-driven token-family revocation through the HTTP API. Docker must be running for infrastructure tests. Testcontainers 1.21.4 is required for current Docker Engine API compatibility.

No performance figures are claimed until k6 scenarios are executed in a representative environment.
